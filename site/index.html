CURRENT PROGRAM / REPRESENTATION × ARCHITECTURE

Research question

What geometry should a language model think in?

Representation–architecture co-design / active

I am testing whether compact geometric representations can preserve task-relevant distinctions while changing the compute and architecture required to consume them. The program combines mathematical elimination with frozen-model experiments so negative results narrow the design space instead of disappearing.

Method
Proof-first constraints, frozen-model probes, controlled consumer repairs, natural-source benchmarks.
Evidence
Checked theorem ledger, executable notebooks, reproducible empirical artifacts, and explicit boundaries on what each result establishes.
