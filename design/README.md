# Portfolio title direction

Option 07, **Long measure**, was selected from the ten local title studies.
The shared site stylesheet applies its upright narrow face, regular weight,
close line spacing, and thin vertical rule to page titles. Home and index
titles use lowercase; published notebook titles retain their source casing.
Section headings use the same face with more space between lines.

The font is bundled under `site/assets/fonts/long-measure/`; visitors do not
need the Linux font used for the original studies installed locally.

`title-review.html` and `render-title-review.mjs` preserve the comparison
exercise. The stylesheet under `site/assets/` is the implemented design.
